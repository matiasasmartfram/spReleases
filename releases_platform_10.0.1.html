Notas de Release: Platform 10.0.1

Este release se centra en la estabilidad de las integraciones con SML y en la mejora de la observabilidad de seguridad en la autenticación.

Información de Despliegue

Resumen General de la Versión

Se han implementado correcciones críticas para asegurar que el sistema espere correctamente las respuestas de los servicios de logística externos, evitando que los pedidos queden en estados inconsistentes. Además, se ha mejorado significativamente el registro de errores de acceso, permitiendo identificar de forma más rápida por qué fallan los inicios de sesión o los tokens de los usuarios.

api/src/app.js

Modificaciones Identificadas

1. Refactorización del Middleware de Manejo de Errores y Observabilidad

Se ha implementado un sistema mucho más robusto para capturar y clasificar errores de autenticación (JWT). Antes se utilizaba un log genérico ("Falló general platform"); ahora el sistema identifica el tipo exacto de fallo (Token faltante, expirado, inválido o permiso denegado) y captura el contexto completo del request (ID, método, URL, body, IP, User-Agent) y del JWT (payload decodificado), lo que mejora drásticamente la capacidad de diagnóstico en producción.

import jwt from 'express-jwt';
import { decode as jwtDecode } from 'jsonwebtoken';
import 'core-js/stable';
import 'regenerator-runtime/runtime';
import checkRoutePermissions from './middlewares/route-permissions';

app.use(function (err, req, res, next) {
  // Mapeo tipo de error de acuerdo a err.message
  let errorType = 'AUTH_UNKNOWN';

  if (err.message.includes('No authorization token was found') || err.message.includes('credentials_required')) {
    errorType = 'TOKEN_MISSING';
  } else if (err.message === 'jwt expired') {
    errorType = 'TOKEN_EXPIRED';
  } else if (err.message === 'invalid signature' || err.message === 'jwt malformed') {
    errorType = 'TOKEN_INVALID';
  } else if (err.message.includes('Permission denied')) {
    errorType = 'PERMISSION_DENIED';
  }

  // Datos origen del request para el log
  const requestId = req.uuid;
  const method = req.method;
  const url = req.originalUrl;
  const body = req.body || null;
  const ip = req.ip;
  const userAgent = req.headers['user-agent'] || 'Unknown';

  // Decode JWT payload para identificar el err.code
  let tokenPresent = !!req.headers.authorization;
  let jwtPayload = null;
  if (tokenPresent && req.headers.authorization.startsWith('Bearer ')) {
    const token = req.headers.authorization.substring(7);
    try {
      jwtPayload = jwtDecode(token);
    } catch (decodeErr) {
      // Si falla el decode de JWT la var jwtPayload asigno null;
    }
  }

  // Log data
  const logObject = {
    message:`Platform Auth Error: ${errorType} ${method} ${url}`,
    errorType,
    requestId,
    platform: 'Platform',
    requestContext: {
      method,
      url,
      body,
      ip,
      userAgent
    },
    authContext: {
      tokenPresent,
      jwtPayload
    }
  };

  Log.saveError(err, logObject);

  // response message
  let msg = err.message;
  if (err.message === 'jwt expired') msg = 'Expired token.';
  if (err.message === 'invalid signature') msg = 'Invalid token.';
  const custerr = new CustomError(CORE.TOKEN, msg, req.uuid);
  return res.status(401).json(custerr).end();
});

Conclusión General

El release 10.0.1 de Platform se centra en dos pilares críticos: la estabilidad de las integraciones y la observabilidad de seguridad. Por un lado, se ha resuelto un problema sistémico de asincronía (missing awaits) en las llamadas hacia el servicio SML (Smart Logistics), lo cual afectaba a múltiples drivers (Rapiboy, ThirdParty, Base Platform). Este cambio evita posibles fallos silenciosos y asegura que el sistema tenga una trazabilidad real del éxito de estas operaciones externas. Por otro lado, la mejora en el middleware de autenticación en app.js dota al equipo de soporte de herramientas mucho más precisas para depurar problemas de tokens expirados o accesos denegados, capturando no solo el error sino el contexto completo del cliente y el contenido del JWT en el momento del fallo.
