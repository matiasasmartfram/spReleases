Resumen General de la Versión

Esta versión actualiza la base tecnológica del panel de administración (Backoffice) desde Angular 8 a Angular 21, la versión actual del framework. El cambio implica una modernización completa de las bibliotecas de interfaz gráfica, el sistema de peticiones HTTP, las animaciones de carga y las herramientas de visualización de datos. Como resultado, la aplicación queda preparada para recibir nuevas funcionalidades sobre una infraestructura tecnológica soportada y actualizada.

Adicionalmente, se actualizan los scripts de publicación en el servidor para adaptarlos al nuevo formato de archivos generado por Angular 21, garantizando que los recursos (JavaScript, CSS, HTML) se sirvan con los tipos de contenido correctos.

deploy-staging.sh

Modificaciones Identificadas

1. Segmentación de Despliegue en AWS S3 por Contenido
Se reemplaza la sincronización directa del directorio dist por una subida segmentada de la carpeta dist/browser/. Primero sincroniza archivos .js con content-type application/javascript, luego archivos .css con text/css, copia individualmente el index.html como text/html y finalmente sincroniza el resto de recursos (assets), asegurando la correcta asignación de cabeceras HTTP en S3.

Código ANTES

# Deploy
aws s3 sync ./dist/ s3://${S3_BUCKET} --profile ${PROFILE}

Código DESPUÉS

# Deploy
# JS
aws s3 sync ./dist/browser/ s3://${S3_BUCKET} \
  --exclude "*" --include "*.js" \
  --content-type "application/javascript"

# CSS
aws s3 sync ./dist/browser/ s3://${S3_BUCKET} \
  --exclude "*" --include "*.css" \
  --content-type "text/css"

# HTML
aws s3 cp ./dist/browser/index.html s3://${S3_BUCKET}/index.html \
  --content-type "text/html"

# resto (assets)
aws s3 sync ./dist/browser/ s3://${S3_BUCKET} \
  --exclude "*.js" --exclude "*.css" --exclude "index.html"

aws s3 sync ./dist/browser/ s3://${S3_BUCKET} \
  --exclude "*" --include "*.css" \
  --content-type "text/css"

# HTML
aws s3 cp ./dist/browser/index.html s3://${S3_BUCKET}/index.html \
  --content-type "text/html"

# resto (assets)
aws s3 sync ./dist/browser/ s3://${S3_BUCKET} \
  --exclude "*.js" --exclude "*.css" --exclude "index.html"

#Invalidate CloudFront caches
aws cloudfront create-invalidation \
    --profile ${PROFILE} \
    --distribution-id ${DISTRIBUTION_ID} \
    --paths "${INVALIDATE_PATH}"

Conclusión General

La migración a Angular 21 marca un hito evolutivo clave en el frontend del Backoffice, reemplazando dependencias antiguas y obsoletas (como Angular 8 y Google Charts) por alternativas modernas y de alto rendimiento como Angular 21 y NgApexcharts. Esta base tecnológica no solo optimiza la reactividad y velocidad de la interfaz mediante la inyección de proveedores de detección de cambios optimizados, sino que también estandariza los flujos de despliegue mediante sincronización segmentada por tipo de contenido en AWS S3. Los cambios en Guards, interceptores y componentes de reportes y estado sientan una infraestructura sólida para futuros desarrollos visuales y de monitoreo.
