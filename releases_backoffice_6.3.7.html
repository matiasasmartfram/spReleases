Resumen General de la Versión

Este release del Backoffice añade soporte para MercadoPago como plataforma de entrega dentro del panel de administración de sucursales. Los operadores ahora pueden gestionar la apertura y cierre de este canal para cada sucursal configurada en el sistema.

Análisis Técnico Detallado

app/src/app/pages/management/branches/branch/branch.component.ts

Modificaciones Identificadas

1. Habilitación de MercadoPago en el Panel de Apertura y Cierre de Sucursales

Se añade "MercadoPago" al listado de plataformas gestionables para apertura y cierre. Esto expone el canal en la interfaz de usuario, permitiendo a los operadores enviar peticiones de cambio de estado hacia el Concentrador para esta plataforma.

2. Mapeo del Identificador de MercadoPago

Se asocia el identificador numérico 8 con la plataforma 'MercadoPago' dentro del mapa de plataformas. Esto asegura que el frontend resuelva correctamente el nombre comercial a partir de los datos recibidos del Concentrador.

Código ANTES

  public platformsOpenClosed = ["Rappi","UberEats","PedidosYa","PediGrido"]
  public platformMap = {
    1: 'PedidosYa',
    2: 'Rappi',

  public platformsOpenClosed = ["Rappi","UberEats","PedidosYa","PediGrido","MercadoPago"]

Conclusión del Archivo

El componente de gestión de sucursales incorpora MercadoPago a sus flujos de control de estado y mapeo interno. Esto permite una administración consistente con los mismos controles y lógica de visualización que ya se utilizan para el resto de los canales de delivery de la sucursal.

Conclusión General

Este release del Backoffice incorpora soporte de interfaz para MercadoPago como canal de delivery, permitiendo su mapeo e inclusión en el panel de control de sucursales. Con este cambio, los operadores disponen de la capacidad de activar o desactivar MercadoPago de manera integrada con las plataformas existentes, sin requerir flujos excepcionales para este canal. La integración mantiene la estructura de datos existente y extiende el control operativo para dar cobertura a nuevas alianzas de comercialización y entrega directa de pedidos de la cadena.
