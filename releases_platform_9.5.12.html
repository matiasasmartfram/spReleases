Resumen General de la Versión

Esta versión introduce una mejora significativa en la forma en que el sistema rastrea y clasifica los tipos de entrega de pedidos (Glovo, Rappi, PedidosYa, etc.). Al estandarizar la variable deliveryType, se facilita la visualización y el procesamiento de pedidos tanto en el Backoffice como en las integraciones logísticas. Además, se ha realizado una actualización importante en la infraestructura de la nube, dotando al servicio de mayor capacidad de memoria y procesamiento para asegurar un rendimiento óptimo bajo alta demanda.

api/src/platforms/interfaces/glovo.js

Estandarización de Tipos de Entrega

Se ha implementado la propiedad deliveryType para normalizar el flujo logístico del pedido. Esto elimina la ambigüedad al consolidar las banderas pickupOnShop y ownDelivery en un valor nominal único: forPickup, forRestaurant o forLogistics.

order.pickupOnShop = data.order.is_picked_up_by_customer || false;
order.preOrder = false;
order.ownDelivery = false;

Código DESPUÉS
order.pickupOnShop = data.order.is_picked_up_by_customer || false;
order.preOrder = false;
order.ownDelivery = false;
order.deliveryType = ''; // Inicialización
if (order.pickupOnShop) {
    order.deliveryType = 'forPickup';
} else if (order.ownDelivery) {
    order.deliveryType = 'forRestaurant';
} else {
    order.deliveryType = 'forLogistics';

container-definitions-prd.json

Escalabilidad y Desacoplamiento de Infraestructura

Se han realizado cambios estructurales en la definición de tareas (Task Definitions) para AWS ECS:

  • Identidad Única: Se desvinculan nombres de logs y tags que antes referenciaban erróneamente a "Concentrador".
  • Networking: Cambio de puerto del 3086 al 3087 para evitar colisiones.
  • Escalabilidad Vertical: Se incrementa el CPU (256 a 512) y se cuatruplica la memoria RAM (512MB a 2048MB) para soportar picos de carga transicionales (OOM Prevention).
Código ANTES (Extracto)
"awslogs-group": "/ecs/concentrador-service-production-task",
"portMappings": [{ "hostPort": 3086, "containerPort": 3086 }],
"cpu": "256",
"memory": "512"
Código DESPUÉS (Extracto)
"awslogs-group": "/ecs/platform-service-production-task",
"portMappings": [{ "hostPort": 3087, "containerPort": 3087 }],
"cpu": "512",
"memory": "2048"
