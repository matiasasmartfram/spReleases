Resumen General de la Versión

Esta actualización introduce mejoras críticas en la visibilidad de pedidos para Rappi, asegurando que las cantidades de modificadores se lean correctamente en los locales. Asimismo, se robustece la integración con MercadoPago mediante un sistema de auto-refresh de tokens ante errores de autenticación y se habilita una nueva vía de consulta de disponibilidad de pedidos para Pedidos Ya.

{ url: /\/order\/?.*/, methods: ['GET', 'POST'] },

const getOrder = async (req, res) => {
    if (!req.params.remoteOrderId) {
        const msg = 'Insuficient parameter.';
        return res.status(400).send({ message: msg }).end();
    }
    let orderId = req.params.remoteOrderId;
    let order = await News.findOne({ 'order.id': orderId }, { orderPickedUp: 1, 'order.originalId': 1, _id: 0 });
    if (!order) {
        return res.status(404).send({
            'msg': 'Orden no encontrada'
        });
    }
    return res.status(200).send({
        'orderId': order ? order.order?.originalId : null,
        'orderPickedUp': order ? order.orderPickedUp : false
    });
};

module.exports = {
    saveOrder,
    updateOrder,
    getOrder
};

api/src/controllers/mercadoPago.js y api/src/platforms/management/platform/mercadoPago.js

Modificaciones Identificadas

1. Gestión Inteligente de Tokens y Reintento Automático (MercadoPago)

Se ha implementado una estrategia de robustez para las llamadas a la API de MercadoPago. El sistema ahora prioriza el uso de tokens cacheados y, ante un error 401, solicita automáticamente un nuevo token y reintenta la operación.

2. Optimización de Persistencia de Tokens en SmartCloud Integration

En el utilitario tokensCloud.js, se ha reemplazado la creación directa de documentos por un findOneAndUpdate con upsert: true para garantizar registro único por user_id.

Conclusión del Archivo

Conclusión General

El release Platform 9.6.2 se centra en la robustez operativa y el enriquecimiento de la información. Las mejoras en Rappi aseguran que la comunicación de cantidades sea inequívoca para los locales, mientras que la nueva API de consulta para Pedidos Ya fortalece las capacidades de monitoreo. Finalmente, la lógica de auto-refresh de tokens para MercadoPago resuelve uno de los puntos de fricción técnica más comunes, posicionando al sistema como una pieza mucho más resiliente y autónoma.
