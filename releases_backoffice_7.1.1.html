Resumen General de la Versión

Este release introduce nuevos filtros en el panel Dashboard (Status) de auditoría del Backoffice. Habilita búsquedas cruzadas por estado de PickedUp, logística de entrega e importe total de ticket para un monitoreo más ágil.

Modificaciones Identificadas

1. Filtro de estado de retiro (Picked Up)

Se incorpora un selector desplegable en el panel de filtros de novedades para permitir filtrar por pedidos retirados o no por el repartidor.

2. Desplegable de tipos de logística de entrega

Se implementa un selector multi-check que expone opciones de filtrado por los distintos métodos de entrega del sistema (Propio, Plataforma, TakeAway).

3. Filtro por monto total

Se agrega un input de texto que permite filtrar de forma directa pedidos que coincidan con un importe total determinado.

Conclusión

La interfaz de usuario del dashboard incorpora los tres nuevos elementos de entrada y selección en el formulario de filtros.

Modificaciones Identificadas

1. Variables de control de nuevos filtros

Se declaran las propiedades selectedDeliveries, deliveryName, pickedUpBoolean, orderTotalAmount y el array de referencia deliveryTypes para coordinar el estado de los nuevos campos desde el controlador Angular.

2. Métodos de interacción y despacho de búsqueda

Se añaden las funciones de respuesta onDeliveryTypeChange y onOrderTotalAmountInput para capturar la interacción de los filtros y despachar los parámetros correspondientes en el payload HTTP enviado a la API de consulta de novedades del Concentrador.

Conclusión

El controlador implementa las variables y métodos necesarios para capturar y enviar las selecciones del usuario en el payload HTTP.
