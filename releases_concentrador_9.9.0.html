Modificaciones Identificadas

1. **Agregar la consulta paginada de logs Open/Closed**

Se incorpora `openClosedLogs`, que recibe el rango de fechas y los filtros de monitoreo, limita la consulta a un máximo de 31 días y devuelve resultados paginados ordenados por `createdAt` descendente. Los filtros de país, cadena y sucursal se traducen a identificadores de sucursal antes de consultar los documentos.

2. **Filtrar y enriquecer los resultados por sucursal**

La respuesta conserva únicamente los elementos de `extraData` y `results` que coinciden con los filtros solicitados. Luego consulta las sucursales involucradas, obtiene la cadena relacionada y el país, y agrega esos datos a cada elemento para que el Backoffice pueda mostrarlos en la grilla.

3. **Exponer el endpoint de exportación**

Se agrega `exportOpenClosedLogs` como handler del flujo de exportación, pero en este commit la función responde `500 Internal server error` sin generar un archivo. El endpoint queda disponible para una implementación posterior.

Conclusión General

El release agrega al Concentrador la API base para la pantalla de monitoreo Open/Closed del Backoffice. El controlador permite consultar logs por rango de fechas y múltiples filtros, paginar los resultados y devolver la cadena y el país asociados a cada sucursal. Las rutas nuevas exponen tanto la consulta como la exportación, pero esta última permanece como un handler que responde con error interno y requiere una implementación posterior para completar ese flujo.
