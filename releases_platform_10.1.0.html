Notas de Release: Platform 10.1.0

Este release introduce un mapeador avanzado para procesar promociones de Rappi que contienen productos a granel, y soluciona múltiples brechas de robustez, control de nulos y tolerancia a fallos en la integración con UberEats.

Resumen General de la Versión

El release Platform 10.1.0 expande la capacidad de integración del backend con los principales agregadores de pedidos. Por una parte, incorpora un procesador inteligente de promociones de Rappi a granel que desglosa automáticamente los subítems y compila sus opciones detalladamente en las notas del ítem. Por otra parte, incrementa drásticamente la estabilidad de la integración con UberEats al implementar resolución por defecto del país de la tienda a nivel de credenciales y rutas HTTP, protección integral frente a datos incompletos de clientes y observabilidad enriquecida de errores mediante try-catch estructurado. Finalmente, agiliza la compilación del Dockerfile y su empaquetado multi-stage, inyectando de forma nativa los certificados SSL para conexiones seguras de red.

api/Dockerfile

Modificaciones Identificadas

1. Obtención automatizada de certificados y compilación multi-etapa (Commit d8012dd)

Se actualiza el flujo de Docker del backend para instalar openssl de forma interactiva en la etapa base y conectarse a bot-security.smartfran.com para volcar el certificado SSL fullchain. En la etapa productiva, se copian de manera transparente todos los certificados CA dinámicos, se ejecutan las actualizaciones de CA en Alpine y se corrigen rutas y tipografía de nombres de etapas (de BASE a base).

Código ANTES

WORKDIR /usr/src/app
COPY package.json .
RUN npm install
...
FROM node:20.20-alpine
RUN apk add --no-cache ca-certificates
COPY sectigo-fullchain.pem /usr/local/share/ca-certificates/sectigo.crt
RUN update-ca-certificates
ENV NODE_EXTRA_CA_CERTS=/etc/ssl/certs/ca-certificates.crt
WORKDIR /usr/src/app
COPY package.json .
RUN npm install --only=production
COPY --from=BASE /usr/src/app/dist ./dist
ENTRYPOINT ["npm", "run"]
CMD ["serve"]

Código DESPUÉS

COPY --from=base /usr/src/app/dist ./dist
ENTRYPOINT ["npm", "run"]
CMD ["serve"]

Conclusión del Archivo

El archivo Dockerfile automatiza la inyección de CA para SmartFran en la compilación y unifica los comandos de copiado multi-etapa, asegurando consistencia en la generación de imágenes de contenedores.

Conclusión General

Este release de Platform representa una mejora sustancial en la robustez y flexibilidad operativa de las integraciones externas de SmartPedidos. Por un lado, la incorporación del parseador de promociones a granel de Rappi amplía la capacidad del backend para procesar estructuras de pedidos avanzadas sin alterar los identificadores SKU principales. Por otro lado, la unificación del webhook de UberEats sin parámetros geográficos obligatorios en combinación con los manejos de try-catch y re-lanzamiento en errores axios y comprobaciones preventivas de nulos mitigan de manera contundente la interrupción de flujos de órdenes. Finalmente, la automatización del aprovisionamiento de certificados SSL dentro del Dockerfile simplifica las tareas de despliegue y compatibilidad TLS con servicios internos de la compañía.
