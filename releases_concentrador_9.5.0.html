Resumen General de la Versión

Este release introduce la funcionalidad de "LoginCloud" para sucursales que operan en la nube. Además, se agrega el soporte y filtrado de motivos de rechazo permitidos según la modalidad de entrega del pedido (`allowedByDeliveryMode`).

En `getRejectedMessages`, la consulta de base de datos se modifica para requerir y retornar el campo `allowedByDeliveryMode`, permitiendo discriminar qué motivos aplican según la modalidad.

const loginCloud = async (req, res) => {
  let params ={ 
    user: req.body.user,
    password :req.body.password
  }
  let findParams = {};
  findParams.permissions = true;
  let user = await userModel.findOne({user: params.user}, {salt: true, password: true  }); 
  if (!user) 
    return res.status(401).json({ error: 'Username or password are incorrect.' }).end(); 
  if(user.salt)
    params.password = sha256(params.password + user.salt).toString(); 
  if (!user.salt){ 
    const randomBytes = require('crypto').randomBytes;
    const salt = randomBytes(16).toString('hex');
    const saltedPassword = user.password + salt;
    const password = sha256(saltedPassword).toString();
    await userModel.updateOne({user: params.user}, {password: password, passwordConfirm: password, salt: salt });    
    params.password = sha256(params.password + salt).toString();
  }
  try { 
    let user = await userModel.findOne(params, findParams); 
    if (!!user) {
      const accessToken = jwt.sign({ user }, settings.token.secret, {  expiresIn: '24h' });
      return res.status(200).json({ data: user, accessToken }).end();
    } 
    else
      throw 'Username or password are incorrect.';    
  } catch (error) { 
    Log.saveError(error, { message: 'Falló loginCloud concentrador', platform: 'Concentrador' });
    return res.status(401).json({ error: error }).end();
  }
};

## Conclusión General del Análisis

Este release habilita la compatibilidad de login en la nube para sucursales mediante cifrado seguro de contraseñas con salt en el Concentrador. Asimismo, introduce filtros a nivel de base de datos para soportar la discriminación de motivos de rechazo por modalidad de entrega (`allowedByDeliveryMode`), optimizando la lógica de rechazos.
