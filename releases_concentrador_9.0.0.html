Concentrador v9.0.0

Modernización Estructural & Depuración de Infraestructura

Major Update Node 20 AWS SDK v3

Visión General

El Release 9.0.0 constituye una actualización mayor del Concentrador, centrada en la eficiencia operativa y la modernización del stack tecnológico. Se ha migrado el runtime a Node 20, se han actualizado las dependencias core a sus versiones más estables y se ha implementado el AWS SDK v3 para una gestión granular de recursos cloud.

Runtime
Node 20.20-alpine
Middleware
Express-JWT v8.5.1
Database
Mongoose v7.8.7

Depuración de Infraestructura (Cleanup)

Se ha realizado un desmantelamiento masivo de archivos y herramientas obsoletas para reducir la superficie de ataque y simplificar el mantenimiento.

  • .gitlab-ci.yml (Eliminado)
  • Jenkinsfile (Eliminado)
  • api/test/functional/* (Suite Python/Behave eliminada)
  • api/seeders/* (Helpers de datos legacy eliminados)
  • api/sonar-project.properties (Eliminado)

Nueva Estrategia de Despliegue (CLI)

Se introducen scripts CLI robustos para orquestar los entornos de Staging y Producción, incorporando validación de ramas y etiquetado múltiple (Tagging) para auditoría.

# deploy-prod.sh snippet
docker build \
        -t ${ECR_REPOSITORY}/${PROJ_IMG}:${BUILD_TAG} \
        -t ${ECR_REPOSITORY}/${PROJ_IMG}:${BUILD_TAG}-${REV_PARSE} \
        ./api/

envsubst < container-definitions-prd.json > ecs-container-definitions.json

Conclusión General

El Concentrador 9.0.0 consolida la modernización técnica del servicio, eliminando años de deuda técnica y estandarizando el ciclo de vida de desarrollo bajo estándares modernos de seguridad y performance.
