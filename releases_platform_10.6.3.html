Resumen General de la Versión

Este release introduce correcciones de seguridad frente a errores de tipo Null Pointer Exception (NPE) y desreferenciación de objetos nulos en los flujos de cancelación y entrega de pedidos. Asimismo, se robustece la inicialización de la plataforma UberEats previniendo caídas críticas del servicio ante credenciales mal configuradas o fallos de parseo JSON.

api/src/platforms/management/platform/uberEats.js

Modificaciones Identificadas

1. **Control de excepciones durante la inicialización de credenciales**
Se envuelven los bloques de lectura y parseo JSON de credenciales (`clientSecret` y `clientId`) en bloques try-catch individuales para arrojar errores descriptivos en caso de JSON inválido.
2. **Estructura general de inicialización segura**
Se encapsula toda la ejecución del método `init()` dentro de un try-catch que captura errores de inicialización y los reporta a través de `Log.saveError`.
3. **Manejo de promesas rechazadas en constructor**
Se añade un manejador `.catch()` al llamado asíncrono de `init()` en el constructor, previniendo promesas rechazadas no manejadas (unhandled promise rejections) en tiempo de ejecución.

  constructor(platform) {
    super(platform);
   // this.urlLogin = 'https://auth.uber.com/oauth/v2/token';
    this.urlGetOrders = 'https://api.uber.com/v1/eats/stores/' + this._platform.credentials.data.store_id + '/orders'
    this.urlGetDetailsOrder = 'https://api.uber.com/v1/delivery/order/';
    this._platform = platform;
    this.tokenUber = {};
    this.init().catch((error) => {
      Log.saveError(error, { category: 'INTEGRATION', message: '[INTEGRATION/ERROR] UberEats init rejected', platform: 'UberEats' });
    });
    this.cronGetPlatformParameters();
    console.log(`${this._platform.name}.\t Inicializated.`);
  }

  async init() {
    try {
      if (
        this._platform &&
        this._platform.credentials &&
        this._platform.credentials.data
      ) {
        try {
          this.clientSecret = JSON.parse(this._platform.credentials.data.clientSecret);
        } catch (error) {
          throw new Error(`Invalid JSON in UberEats credentials.clientSecret: ${error.message}`);
        }

        try {
          this.clientId = JSON.parse(this._platform.credentials.data.clientId);
        } catch (error) {
          throw new Error(`Invalid JSON in UberEats credentials.clientId: ${error.message}`);
        }

        this.baseUrl = this._platform.credentials.data.baseUrl;
        await this.uberLogin();
        this.statusResponse = this._platform.statusResponse;
      } else {
        const msg = 'Can not initializate UberEats.';
        new CustomError(APP_PLATFORM.INIT, msg, this.uuid, {
          platform: this._platform
        });
      }
    } catch (error) {
      Log.saveError(error, { category: 'INTEGRATION', message: '[INTEGRATION/ERROR] UberEats init failed', platform: 'UberEats' });
    }
  }

Conclusión del Archivo

Se incrementa la robustez de la inicialización de la integración de UberEats mitigando fallas catastróficas del proceso ante errores de sintaxis JSON en la base de datos de credenciales, y controlando de manera segura el rechazo de promesas.

Conclusión General

Este release introduce protecciones frente a errores de tipo Null Pointer Exception en los flujos comunes de cancelación y entrega (ThirdParty/Rapiboy), lo que previene potenciales interrupciones en la ejecución de la API de backend. Adicionalmente, se dota de mayor resiliencia al proceso de inicialización de UberEats mediante una contención de excepciones estructurada y segura ante configuraciones de credenciales corruptas. Es una versión enfocada en estabilidad y seguridad, sin impacto en la lógica de negocio.
