Notas de Release: Concentrador 9.7.0

Este release del Concentrador implementa la configuración dinámica y sincronización de horarios de Check-In para las plataformas integradas, eliminando crons estáticos y exponiendo nuevos endpoints.

Resumen General de la Versión

Este release habilita la administración de Check-Ins desde base de datos, lo que permite configurar y planificar horas de validación personalizadas para cada plataforma desde el Backoffice sin requerir modificaciones en el código base.

Análisis Técnico Detallado

api/src/controllers/branch.js

Modificaciones Identificadas

1. Reemplazo de crons estáticos por sincronización dinámica de Check-Ins

Se eliminan los arrays estáticos de horarios (pedidosYaTimes, rappiTimes, etc.) y sus correspondientes planificaciones de cron al inicio. En su lugar, se invoca sincroCheckIns para cada plataforma activa.

2. Implementación de checkforcedCheckins y sincroCheckIns

Se introducen funciones asíncronas para buscar plataformas con sincronización pendiente y registrar dinámicamente cronjobs basados en platform.checkIns, destruyendo de forma segura los cronjobs antiguos.

Código DESPUÉS

const getPlatformsCheckIns = async (req, res) => {
  let data = await model.findOne({internalCode: req.params.id}).select('name checkIns checkInActive -_id');
  return res.status(200).json({data}).end();
};

const savePlatformsCheckIns = async (req, res) => {
  try {
    const { platformId, checkInActive, checkIns } = req.body;
    const result = await model.updateOne(
      { internalCode: platformId },
      {
          $set: {
              checkInActive: checkInActive,
              alreadySincro: false,
              checkIns: checkIns
          }
      }
    );
    return res.status(200).json({ message: "Configuración actualizada con éxito" }).end();
  } catch (error) {
    Log.saveError(error, { category: 'INFRA', message: '[INFRA/ERROR] failed savePlatformsCheckIns insert', data: req.body, platform: 'Concentrador' });
    return res.status(400).json(error).end();
  }  
};

module.exports = {

  updateOne,
  deleteOne,
  getPlatformsHistory,
  getPlatformsCheckIns,
  savePlatformsCheckIns
};

Conclusión General

Este release introduce una reestructuración del mecanismo de Check-In del Concentrador. Se abandona el esquema rígido de cronjobs programados de forma estática en el código base y se migra a un motor de planificación dinámico basado en base de datos. La nueva arquitectura permite configurar e iniciar chequeos automatizados de estado a nivel de plataforma mediante la API consumida desde el Backoffice, optimizando la flexibilidad operativa.
