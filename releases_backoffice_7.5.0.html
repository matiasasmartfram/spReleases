Resumen General de la Versión

Este release incorpora en el formulario de plataformas un control para actualizar la Base URL sin depender de un reinicio de Platform. El operador puede guardar el valor directamente desde cada sección de configuración y recibe una confirmación de éxito o un mensaje de error.

Análisis Técnico Detallado

app/src/app/pages/management/platforms/platform/platform.component.html

Modificaciones Identificadas

1. **Agregar el botón de recarga junto a Base Url**

Las secciones de configuración de plataformas muestran un botón con ícono de sincronización junto al campo Base Url. El control se deshabilita en la vista de consulta y ejecuta `updateBaseUrl()` en las vistas editables.

2. **Aplicar el control a las distintas configuraciones**

El botón se incorpora en los tres bloques del formulario donde se administra la Base URL, manteniendo el input existente y sus reglas de solo lectura.

Conclusión

El formulario de plataformas permite iniciar la actualización de Base URL desde la misma pantalla donde se edita el valor. La acción queda disponible solo cuando la vista permite modificar la plataforma.

app/src/app/pages/management/platforms/platform/platform.component.ts

Modificaciones Identificadas

1. **Guardar la plataforma seleccionada**

Se incorpora `idPlatform` para conservar el identificador de la plataforma cargada y reutilizarlo al solicitar la actualización de Base URL.

2. **Ejecutar la actualización desde la interfaz**

`updateBaseUrl()` envía el identificador y el valor actual del formulario al servicio HTTP. La respuesta exitosa muestra “Los cambios se guardaron correctamente.” y los errores muestran el mensaje existente de fallo de guardado.

3. **Mantener el flujo de carga existente**

El identificador se asigna al cargar una plataforma en las vistas de consulta o edición; el alta de una plataforma nueva conserva el flujo de inicialización actual.

Conclusión

El componente de plataforma incorpora la acción de actualización inmediata y comunica el resultado al operador mediante SweetAlert. El valor enviado corresponde al campo Base URL actualmente editado y queda asociado a la plataforma seleccionada.

Modificaciones Identificadas

1. **Agregar la llamada HTTP de actualización**

`updateBaseUrl` envía una solicitud `PUT` a `/thirdParty/updateBaseUrl` con el identificador de la plataforma y la Base URL recibida del formulario.

Conclusión

El servicio de plataformas encapsula el nuevo endpoint y deja al componente separado de la construcción de la solicitud HTTP.
