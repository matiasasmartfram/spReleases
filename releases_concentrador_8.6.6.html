Implementación y estabilización de la gestión de disponibilidad para MercadoPago.

Fecha de Despliegue: 06/04/2026

AWS Task: 282

Commits: 6e8d351e55194b8724c7da8ccbb2ccb1c69d3086

Resumen General de la Versión

Esta actualización introduce capacidades avanzadas para la gestión automatizada del estado de las sucursales integradas con MercadoPago. El sistema ahora permite detectar desconexiones del punto de venta (POS) y notificar automáticamente el cierre a la plataforma externa para evitar pedidos fallidos. Se incluyeron mejoras en la trazabilidad de errores y una reestructuración en el orden de carga de credenciales para garantizar la estabilidad del servicio. Finalmente, se ha procedido a inactivar preventivamente estas funciones mediante comentarios en el código, permitiendo una reactivación rápida cuando sea necesario.

Dinamización de Tareas Programadas

Se introduce una nueva tarea cron `scheduleGetInfoBranchesMercadoPago` que permite la verificación automatizada del estado de las sucursales vinculadas a MercadoPago. El código ahora incluye mecanismos para detectar si el POS de una tienda está fuera de línea y notificar el estado como cerrado.

  cron.schedule(scheduleOrderRejClosed, async () => await orderRejClosed());
  cron.schedule(scheduleOrerTimesAvg, async () => await initialData.ordertimesAvgCron());

Código DESPUES
  cron.schedule(scheduleOrderRejClosed, async () => await orderRejClosed());
  cron.schedule(scheduleOrerTimesAvg, async () => await initialData.ordertimesAvgCron());

api/src/controllers/branch.js (Tokensload Priority)

Priorización de Carga de Tokens

Se modifica el flujo de inicialización del job cron. Ahora `tokensLoad()` se ejecuta de forma prioritaria ANTES de realizar el `peyaLogin()`. Esto garantiza que todas las variables estén disponibles antes del primer login.

        await tokensLoad();
        await pediGridoLogin();

        await peyaLogin(peyaBaseUrl);
