Resumen General de la Versión

Esta versión corrige un problema en la integración con UberEats que producía pérdida de pedidos. Cuando UberEats enviaba una notificación de nuevo pedido, SmartPedidos tardaba varios segundos en responder porque procesaba el pedido de forma completa antes de contestar. UberEats interpretaba esa demora como un fallo del sistema y podía dejar de enviar órdenes.

A partir de esta versión, SmartPedidos confirma la recepción de la notificación en forma inmediata, guarda el pedido en una lista de espera interna, y lo procesa en segundo plano cada 5 segundos. Esto garantiza que UberEats siempre recibe una respuesta rápida, mientras que el pedido se procesa correctamente en los segundos siguientes. Además, se incorporan alertas automáticas para detectar acumulaciones inusuales de pedidos o eventos que lleven demasiado tiempo sin procesarse.

Modificaciones Identificadas

1. Introducción de Cola en Memoria y Cron para Procesamiento Asíncrono

El webhook uberNotification deja de procesar el pedido en el mismo ciclo de la request. Los eventos entrantes se acumulan en el array ordenesUber y el webhook responde 200 de inmediato. Un cron job configurado con node-cron (cada 5 segundos) toma los elementos de la cola y ejecuta el procesamiento completo: consulta a la API de UberEats, validación, persistencia en Mongo y registro de latencia.

2. Respuesta 200 Inmediata al Webhook de UberEats

UberEats requiere una respuesta rápida a sus notificaciones; si no la recibe, puede interpretar el webhook como caído y dejar de enviar eventos. ANTES, la respuesta 200 solo se enviaba después de que la orden fuera completamente procesada, lo que podía llevar varios segundos. DESPUÉS, la respuesta 200 se emite al encolar el evento, desacoplando el ACK del procesamiento.

3. Mecanismo de Lock para Prevenir Procesamiento Concurrente

Se introduce el par isProcessing / lastProcessingStart. Si el cron se dispara mientras hay un ciclo activo, lo omite. Si el ciclo activo lleva más de 30 segundos sin liberar el lock, se registra el error y se fuerza la liberación para evitar que la cola quede bloqueada indefinidamente.

4. Expiración y Monitoreo de la Cola

Al inicio de cada ciclo del cron, las órdenes con más de 24 horas en cola se eliminan y se registra el evento. Si el largo de la cola supera 50 elementos, se genera un log de advertencia con el detalle de los elementos pendientes. Ambas alertas permiten detectar acumulación anómala de notificaciones.

5. Corrección en la Resolución de Colisiones de ID

ANTES, cuando el hash del ID de UberEats colisionaba con un pedido existente en MongoDB, el código buscaba el último documento de uberCheckOrder usando .exec() con callback. Dado que newId se asignaba dentro del callback pero se usaba fuera, existía una condición de carrera en la que el ID podía quedar sin actualizar. DESPUÉS, la búsqueda usa await y filtra explícitamente el rango [700, 1.000.000) para obtener el mayor ID asignado en ese rango y generar el siguiente.

6. Cambio en el Tratamiento de Órdenes Duplicadas

ANTES, si uberCheckOrder ya contenía el token de la orden, el webhook retornaba 400 a UberEats, lo que podía disparar reintentos por parte de la plataforma. DESPUÉS, el elemento se descarta silenciosamente: se registra el evento en el log y se marca como procesado, permitiendo que el ciclo del cron continúe con el resto de la cola sin interrupciones.

import axios from 'axios';
import Log from '../utils/log';
import orderModel from '../models/order';
import branchModel from '../models/branch';
import uberCheckOrderModel from '../models/uberCheckOrder';
import NewsStateSingleton from '../utils/newsState';
import SetNews from '../platforms/management/strategies/set-news';
import NewsTypeSingleton from '../utils/newsType';
import orderTimeModel from '../models/orderTime';
import initPlatform from '../utils/initPlatform';
import sanitizeHeaders from '../utils/sanitizeHeaders';

const crypto = require('crypto');
const mongoose = require('mongoose');

let _platformInstance = null;

const uberNotification = async (req, res) => {
  try {
    let event = req.body.event_type;
    const requestBody = req.body;
    const calculatedSignature = crypto.createHmac('sha256', 'xxx') // [INFORMACIÓN SENSIBLE PROTEGIDA]
                                      .update(JSON.stringify(requestBody))
                                      .digest('hex');
    if (calculatedSignature === req.headers['x-uber-signature']) {
      switch(event) {
        case 'orders.notification':
          try {
              const entryDate = new Date();
              const orderId = req.body.meta.resource_id;
              // reuse cached platform instance (one per internalCode)
              if (!_platformInstance) _platformInstance = await initPlatform(4, req.uuid);
              const platform = _platformInstance;

              let urlAvailability = `${platform._platform.credentials.data.baseUrl}/v1/delivery/order/${orderId}?expand=carts,payment,deliveries`;

              const headersConfig = {
                headers: {
                  'Authorization': `Bearer ${platform.tokenUber[req.params.country] || platform.tokenUber['Chile']}`,
                }
              };
              let uberOrder;

              try {
                  uberOrder = await axios.get(urlAvailability, headersConfig);
              } catch (error) {
                  Log.saveError(error, {
                      category: 'ORDER', message: '[ORDER/ERROR] consulta orden uber failed',
                      platform: 'UberEats',
                      header: sanitizeHeaders(headersConfig),
                      url: urlAvailability,
                      status_code: error?.response?.status ?? 'unknown'
                  });
                  throw error;
              }

              let order = uberOrder.data.order;
              let currentBranch = await branchModel.findOne({ 'platforms.platform': new mongoose.Types.ObjectId(platform._platform.id), 'platforms.branchReference': order.store.id });
              order.branchId = currentBranch.branchId;
              order.state = "PENDING";

              let orderCheck = await uberCheckOrderModel.find({
                token: order.id
              }).lean();

              if (orderCheck.length) {
                const error = {
                    code: 'bad_request',
                    message: `order ${order.id} already exists`,
                    metadata: {}
                }
                return res.status(400).json(error).end();
              }
              let newId = Number(BigInt('0x' + crypto.createHash('sha256').update(order.id).digest('hex')).toString().slice(0, 9));

              orderCheck = await orderModel.find({
                "order.id": newId,
                internalCode: platform.internalCode,
                state: { $ne: NewsStateSingleton.stateByCod('rej_closed') }
              })
              .lean();

              if (orderCheck.length) {
                  await uberCheckOrderModel.findOne().sort({createdAt:-1}).exec((err, doc)=> {
                      newId =  doc ? doc.orderId + 1 : 700;
                  })
              }

              await uberCheckOrderModel.create({
                token: order.id,
                orderId: newId
              });
              order.oldId = order.id;
              order.id = newId;

              platform.validateNewOrders(order).then(async (ordersSaved) => {

                if (ordersSaved.state === 'CLOSED_RESTAURANT_REJECTED') {
                  urlAvailability = `${platform._platform.credentials.data.baseUrl}/v1/delivery/order/${orderId}/deny`;
                  let body = {
                      deny_reason: {
                          info: "CLOSED_RESTAURANT_REJECTED",
                          type: "STORE_CLOSED",
                          client_error_code: "408",
                          item_metadata: {}
                      }
                  };
                  await axios.post(urlAvailability, body, headersConfig);
                  return res.status(200).json({}).end();;
                }
                await orderTimeModel.create({
                  order: newId,
                  branch: currentBranch.branchId,
                  platformId: 4,
                  platform: "UberEats",
                  cloud: ordersSaved.cloud ? ordersSaved.cloud : false,
                  latencyTimestamp: {
                      platformDate: order.created_time,      // Creación original en la Plataforma
                      entryDate: entryDate,         // Llegada del request a SmartPedidos
                      responseDate: new Date(),      // Respuesta inicial (ACK 200) de SP
                      sendSqsDate: ordersSaved.sendSqsDate       // Envío del mensaje a la cola del POS
                  }
                })
                return res.status(200).json({}).end();
              });
          } catch (error) {
            Log.saveError(error, {  category: 'ORDER', message: '[ORDER/ERROR] orders.notification uber failed', platform: 'UberEats'});
            res.status(500).send('Error interno del servidor');
          }
          break;
        case 'orders.failure':
          try {
            let orderToCancel = await orderModel.findOne({'order.oldId': req.body.meta.resource_id});
            let setNews = new SetNews(req.token);
            let newToSet = { typeId: NewsTypeSingleton.idByCod('platform_rej_ord') };
            const result = await setNews.setNews(newToSet, orderToCancel.order.id);
            return res.status(200).json({}).end();
          } catch (error) {
            Log.saveError(error, {  category: 'ORDER', message: '[ORDER/ERROR] orders.failure uber failed', platform: 'UberEats', body: req.body, bodyuse: req.body.meta.resource_id});
            res.status(200).send('Error interno del servidor');
          }

      }
    } else {
      res.status(401).send('No fue posible validar');
    }
  } catch (error) {
    Log.saveError(error, {  category: 'ORDER', message: '[ORDER/ERROR] general uber failed', platform: 'UberEats'});
    res.status(500).send('Error interno del servidor');
  }
}

module.exports = {
  uberNotification
}

import axios from 'axios';
import Log from '../utils/log';
import orderModel from '../models/order';
import branchModel from '../models/branch';
import uberCheckOrderModel from '../models/uberCheckOrder';
import NewsStateSingleton from '../utils/newsState';
import SetNews from '../platforms/management/strategies/set-news';
import NewsTypeSingleton from '../utils/newsType';
import orderTimeModel from '../models/orderTime';
import initPlatform from '../utils/initPlatform';
import sanitizeHeaders from '../utils/sanitizeHeaders';
import cron from 'node-cron';

const crypto = require('crypto');
const mongoose = require('mongoose');

let _platformInstancePromise = null;
let ordenesUber = [];
let isProcessing = false;
let lastProcessingStart = 0;

const scheduleOrders = '*/5 * * * * *';
cron.schedule(scheduleOrders, async () => await processUberQueue());

async function processUberQueue() {
  try {
    console.log('[CRON] Revisando ordenes pendientes uberEats...');
    if (isProcessing) {
      // 30 segundos tolerancia
      if (Date.now() - lastProcessingStart > 30000) {
        Log.saveError(null, { message: 'uberEats 30000', platform: 'uberEats' });
        isProcessing = false;
      } else {
        return;
      }
    }
    isProcessing = true;
    lastProcessingStart = Date.now();

    const oneDayAgo = new Date(Date.now() - 24 * 60 * 60 * 1000);// 24 horas atra
    let orderfail = ordenesUber.filter(r => r.enterDateSP < oneDayAgo);
    if(orderfail.length > 0){
      Log.saveError(null, { message: 'Missing UberEats delivery orderfail', data: orderfail, platform: 'UberEats' });
      ordenesUber = ordenesUber.filter(order => order.enterDateSP >= oneDayAgo);
    }
    if(ordenesUber.length > 50)  Log.saveError(null, { message: 'WARNING High volume of UberEats orders', count: ordenesUber.length, ordenes: ordenesUber, platform: 'UberEats' });
    const processedElements = [];
    for (const element of ordenesUber) {
      try {
        const entryDate = element.enterDateSP;
        const body = element;
        let event = body.event_type;

        if (!_platformInstancePromise)
          _platformInstancePromise = await initPlatform(4, element.uuid);

        const platform =_platformInstancePromise;
        if (event === 'orders.notification') {
          const orderId = body.meta.resource_id;
          let urlAvailability = `${platform._platform.credentials.data.baseUrl}/v1/delivery/order/${orderId}?expand=carts,payment,deliveries`;

          const headersConfig = {
            headers: {
              'Authorization': `Bearer ${platform.tokenUber[element.orderUberSync.countryOrderUber] || platform.tokenUber['Chile']}`,
            }
          };

          let uberOrder;
          try {
              uberOrder = await axios.get(urlAvailability, headersConfig);
          } catch (error) {
              Log.saveError(error, {
                  message: 'Falló consulta orden uber',
                  platform: 'UberEats',
                  url: urlAvailability,
                  headers: headersConfig
              });
              throw error;
          }
          let order = uberOrder.data.order;

          let currentBranch = await branchModel.findOne({
            'platforms.platform': new mongoose.Types.ObjectId(platform._platform.id),
            'platforms.branchReference': order.store.id
          });

          order.branchId = currentBranch.branchId;
          order.state = "PENDING";

          let orderCheck = await uberCheckOrderModel.find({ token: order.id }).lean();
          if (orderCheck.length){
            Log.saveError(new Error('Order already exists'), { message: 'Order already exists', orderId: order.id, platform: 'UberEats' }); // Ya existe, skip
            processedElements.push(element);
            continue;
          }

          let newId = Number(BigInt('0x' + crypto.createHash('sha256').update(order.id).digest('hex')).toString().slice(0, 9));

          let orderCheck2 = await orderModel.find({
                "order.id": newId,
                internalCode: platform.internalCode,
                state: { $ne: NewsStateSingleton.stateByCod('rej_closed') }
              }).lean();

          if (orderCheck2.length) {
            const doc = await uberCheckOrderModel.findOne({
              orderId: { $gte: 700, $lt: 1000000 }
            }).sort({ orderId: -1 }).lean();
            newId = doc ? doc.orderId + 1 : 700;
          }

          await uberCheckOrderModel.create({
            token: order.id,
            orderId: newId
          });

          order.oldId = order.id;
          order.id = newId;

          let ordersSaved = await platform.validateNewOrders(order);

          await orderTimeModel.create({
            order: newId,
            branch: currentBranch.branchId,
            platformId: 4,
            platform: "UberEats",
            cloud: ordersSaved.cloud ? ordersSaved.cloud : false,
            latencyTimestamp: {
              platformDate: order.created_time,
              entryDate: entryDate,
              responseDate: new Date(),
              sendSqsDate: ordersSaved.sendSqsDate
            }
          });
        }

        if (event === 'orders.failure') {
          let orderToCancel = await orderModel.findOne({'order.oldId': body.meta.resource_id});
          let setNews = new SetNews(element.orderUberSync.tokenOrderUber);
          let newToSet = { typeId: NewsTypeSingleton.idByCod('platform_rej_ord') };
          await setNews.setNews(newToSet, orderToCancel.order.id);
        }
        processedElements.push(element);
      } catch (error) {
        processedElements.push(element);
        Log.saveError(error, { message: 'Falló procesamiento order UberEats', element: element, platform: 'UberEats' });
        continue;
      }
    }
    // Eliminar procesados exitosamente
    ordenesUber = ordenesUber.filter(r => !processedElements.includes(r));
  }
  catch (error) {
    Log.saveError(error, { message: 'UberEats getOrders general Error', platform: 'UberEats' });
  } finally {
    isProcessing = false;
  }
}

const uberNotification = async (req, res) => {
  try {
    const calculatedSignature = crypto.createHmac('sha256', 'xxx') // [INFORMACIÓN SENSIBLE PROTEGIDA]
                                      .update(JSON.stringify(req.body))
                                      .digest('hex');
    if (calculatedSignature !== req.headers['x-uber-signature']) {
      return res.status(401).send('No fue posible validar firma de Uber');
    }
    let itemQueue = {
      ...req.body,
      enterDateSP: new Date(),
      uuid: req.uuid,
      orderUberSync: {
        countryOrderUber: req.params.country,
        tokenOrderUber: req.token
      }
    };
    ordenesUber.push(itemQueue);
    return res.status(200).json({}).end();
  } catch (error) {
    Log.saveError(error, {  category: 'ORDER', message: '[ORDER/ERROR] general uber failed', platform: 'UberEats'});
    res.status(500).send('Error interno del servidor');
  }
}

Conclusión del Archivo

El controlador de UberEats pasa de un modelo síncrono, donde cada notificación bloqueaba la respuesta HTTP hasta completar el procesamiento del pedido, a un modelo de cola desacoplada. El webhook acusa recibo de forma inmediata y un cron job consume la cola de manera periódica. La resolución de colisiones de ID queda corregida con una consulta await explícita, y el tratamiento de duplicados deja de retornar 400 para evitar reintentos innecesarios de UberEats.

Conclusión General

Este release interviene exclusivamente en la integración con UberEats dentro de Platform. El cambio central es arquitectónico: el webhook de notificaciones deja de procesar órdenes en el contexto de la request HTTP y pasa a funcionar como un punto de ingesta que encola los eventos para consumo diferido. Esto elimina el escenario en el que UberEats dejaba de enviar notificaciones porque el webhook no respondía dentro de su ventana de espera.

El procesamiento asíncrono introduce mecanismos de operabilidad: un lock con auto-liberación por timeout, alertas por volumen alto de cola y expiración automática de eventos con más de 24 horas. Junto con la corrección de la condición de carrera en la asignación de IDs y el cambio en el manejo de duplicados, el release estabiliza el flujo de ingesta de órdenes de UberEats sin afectar otras plataformas ni componentes del sistema.
