Resumen General de la Versión

Este release del Backoffice introduce una nueva herramienta de descarga que facilita la obtención de un archivo Excel consolidado de las sucursales del sistema y la configuración de sus plataformas de delivery, mejorando la auditoría y gestión de sucursales activas.

Se crea la pantalla que contiene la configuración de los filtros de Cadenas, Países y Plataformas, la barra de progreso del proceso de descarga y los botones de acción para volver o ejecutar la exportación.

Modificaciones Identificadas

1. Lógica de filtrado y generación de archivo Excel

Se implementa el comportamiento del controlador de Angular para recuperar datos paginados de sucursales desde el Concentrador de forma asíncrona, recopilar los registros y convertirlos a formato estructurado Excel utilizando la librería XLSX.

Conclusión

El controlador implementa la lógica de consumo y exportación de datos a planillas de Excel.
