Resumen General de la Versión

Este release soluciona un problema en la persistencia de logs de error del Concentrador en la base de datos (MongoDB), donde los objetos de tipo `Error` se guardaban vacíos o con la representación "[Object object]". Se introduce un serializador dinámico para objetos planos y se asegura la asincronía en las llamadas de base de datos de logs.

Análisis Técnico Detallado

api/src/utils/log.js

Modificaciones Identificadas

1. **Introducción del método `serializeError`**
Se crea una función de utilidad interna que convierte cualquier instancia de `Error` en un objeto JavaScript plano recorriendo todas sus propiedades (incluso no enumerables como `stack` y `message`) mediante `Object.getOwnPropertyNames`.
2. **Serialización del error en la persistencia de logs**
Se reemplaza la estructura de guardado parcial del error por el objeto plano serializado de forma completa, evitando que MongoDB guarde estructuras no mapeadas de la clase nativa `Error`.
3. **Manejo asíncrono con `await`**
Se añade `await` a las llamadas de creación de logs en Mongoose (`logErrorModel.create`), garantizando el flujo secuencial y la captura de excepciones durante el guardado de los logs en base de datos.

Código ANTES

class Log {
    static saveError(error, customData = {}) {
        try {
            let customDataAfter = { ...customData };
            delete customDataAfter.message;
            try { 
                logErrorModel.create({
                    message: customData.message,
                    error:{ 
                        error: error?.toString() || 'Unknown error', 
                        message:  error?.message || 'Unknown message',
                        stack: error?.stack || '',                     
                        customDataAfter
                    }
                });
              } catch (ex) {
                console.log(ex)
                if(customData.platform) {
                    logErrorModel.create({
                        message: customData.message,
                        error: { error: `Error inesperado en ${customData.message}`, platform: customData.platform }
                    });

                } else {
                    logErrorModel.create({
                        message: customData.message,
                        error: { error: `Error inesperado en ${customData.message}`}
                    });
                }
              }
        } catch (dbError) {
            logErrorModel.create({
                message: 'Error saveError',
                error: { error: `Error inesperado en saveError`}
            });
        }
    }
}

class Log {
    static async saveError(error, customData = {}) {
        try {
            let customDataAfter = { ...customData };
            delete customDataAfter.message;
            try { 
                await logErrorModel.create({
                    message: customData.message,
                    error:{ 
                        error:Log.serializeError(error)  || 'Unknown error',
                        customDataAfter
                    }
                });
              } catch (ex) {
                if(customData.platform) {
                    await logErrorModel.create({
                        message: customData.message,
                        error: { error: `Error inesperado en ${customData.message}`, platform: customData.platform }
                    });

                } else {
                    await logErrorModel.create({
                        message: customData.message,
                        error: { error: `Error inesperado en ${customData.message}`}
                    });
                }
              }
        } catch (dbError) {
            await logErrorModel.create({
                message: 'Error saveError',
                error: { error: `Error inesperado en saveError`}
            });
        }
    }
    
    // Función para convertir el error a un objeto plano completo
    static serializeError = (err) => {
        if (!(err instanceof Error)) return err;
        return Object.getOwnPropertyNames(err).reduce((acc, key) => {
            acc[key] = err[key];
            return acc;
        }, {});
    };
}

Conclusión del Archivo

Se corrigen y robustecen las llamadas de logueo, permitiendo serializar correctamente cualquier instancia de error sin perder metadatos al persistirlo en la base de datos de auditoría.

Conclusión General

Este release introduce una mejora técnica crítica de observabilidad en el Concentrador al corregir el bug de serialización de errores que persistía objetos vacíos en base de datos.
