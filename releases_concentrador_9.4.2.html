Resumen General de la Versión

Este release introduce la actualización de las credenciales del servicio de envíos de correos (SendGrid API Key) y restringe la ejecución automática de la tarea de verificación de cambios en la diferencia horaria (UTC) de las sucursales para que opere únicamente en el entorno de producción, modificando asimismo el horario del cron job a horas de baja transaccionalidad.

Análisis Técnico Detallado

api/src/config/env/production.js

Modificaciones Identificadas

1. **Actualización de credenciales de SendGrid**
Se reemplaza la clave de API de SendGrid en el archivo de configuración de producción por una nueva clave activa. El secreto original ha sido enmascarado por seguridad.

Conclusión del Archivo

Se actualizan de forma segura las variables de conexión del servicio de correo saliente para producción.

api/src/controllers/branch.js

Modificaciones Identificadas

1. **Restricción de entorno para el cron job de UTC**
Se añade una condición lógica para evitar registrar y ejecutar el cron job de verificación horaria en entornos de desarrollo o pruebas.
2. **Replanificación horaria de la tarea cron**
El cron job se reconfigura para ejecutarse a las 04:00 AM todos los días (cron: `'0 4 * * *'`), en lugar de las 12:00 PM al mediodía (cron: `'0 12 * * *'`), minimizando el uso de recursos durante el horario comercial pico.

Código ANTES

async function syncCheckUTC() {
  const schedule = '0 12 * * *';
  cron.schedule(schedule, async () => await checkUTC.checkUTC());
}

Código DESPUÉS

async function syncCheckUTC() {
  if ( process.env.NODE_ENV === 'production'){
    const schedule = '0 4 * * *';
    cron.schedule(schedule, async () => await checkUTC.checkUTC());
  }
}

Conclusión del Archivo

La verificación automática de diferencias UTC se optimiza para ejecutarse sólo en el entorno de producción y fuera del horario de mayor carga transaccional de las tiendas.

Modificaciones Identificadas

1. **Restricción de entorno para el chequeo de inicio**
La llamada de inicialización asíncrona de `checkUTC.checkUTC()` al iniciar la app se condiciona para ejecutarse exclusivamente en el entorno de producción.

Conclusión del Archivo

Se previene la ejecución de la consulta de diferencia horaria UTC en servidores locales o de staging durante el inicio del backend.

Conclusión General

Este release introduce una nueva clave de SendGrid para asegurar el envío de notificaciones y restringe la tarea automática de control de desfase horario (UTC) a entornos productivos. El ajuste en la planificación del cron (04:00 AM) previene la sobrecarga de consultas en horarios pico de ventas de las franquicias.
