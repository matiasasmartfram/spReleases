Resumen General de la Versión

Este release incorpora un cierre activo de sucursales en todas las plataformas tras el rechazo automático de órdenes con estado cerrado (orderRejClosed). Cuando el Concentrador detecta que una sucursal tiene órdenes rechazadas por estar cerrada, ahora ejecuta un cierre explícito en PedidosYa, Rappi, UberEats, PediGrido y MercadoPago para cada plataforma activa, con manejo de errores individualizado por plataforma.

Modificaciones Identificadas

1. Nueva función sendClosedToPlatformsAfterRejectClosed() — cierre activo post-rechazo

Se agrega una función que, dado un branchId, obtiene la sucursal de la base de datos, filtra sus plataformas activas y ejecuta el cierre en cada una usando las funciones específicas por plataforma (closeBranchPeya, closeBranchRappi, closeBranchUber, closeBranchPediGrido, closeBranchMercadoPago). Usa Promise.allSettled para no interrumpir el proceso si una plataforma falla, registrando el error de cada una de forma independiente.

2. Nuevas funciones de cierre por plataforma

Cada función maneja el cierre en su plataforma correspondiente: obtiene el token correcto (incluyendo por país para Rappi y UberEats), construye el cuerpo y la URL apropiados, ejecuta el PUT y registra el error con metadatos estructurados si la llamada falla.

3. Invocación de sendClosedToPlatformsAfterRejectClosed() desde orderRejClosed()

Dentro de orderRejClosed(), se agrega el bloque que extrae los branchId únicos de las noticias con órdenes rechazadas por cierre y llama a sendClosedToPlatformsAfterRejectClosed() para cada uno. También se reordena la lógica: el updateMany (marca como enviadas) se ejecuta antes del procesamiento, y el map de newsIds se mueve al inicio del flujo para usarse en ambas operaciones.

4. Uso de tokenUber por país en closeBranchUber()

La función de cierre para UberEats construye el header de autorización usando tokenUber[branch.address?.country], alineándose con el modelo multi-país introducido en 9.1.0.

async function sendClosedToPlatformsAfterRejectClosed(branchId) {
  try {
    const branch = await model.findOne({ branchId: branchId });
    
    if (!branch) {
      console.log(`Branch ${branchId} no encontrado`);
      return;
    }

    const activePlatforms = branch.platforms?.filter(p => p.isActive) || [];

    await Promise.allSettled(activePlatforms.map(async (platform) => {
      const platformId = platform.platform?.toString();

      try {
        if (platformId === peyaId?.toString()) {
          await closeBranchPeya(branch, platform);
        } else if (platformId === rappiId?.toString()) {
          await closeBranchRappi(branch, platform);
        } else if (platformId === uberId?.toString()) {
          await closeBranchUber(branch, platform);
        } else if (platformId === pedigridoId?.toString()) {
          await closeBranchPediGrido(branch, platform);
        } else if (platformId === mercadopagoId?.toString()) {
          await closeBranchMercadoPago(branch, platform);
        }
      } catch (error) {
        Log.saveError(error, {
          message: `Error cerrando branch ${branchId} en plataforma ${platformId}`,
          branchId: branchId,
          platformId: platformId
        });
      }
    }));

    console.log(`Branch ${branchId} cerrado en todas las plataformas`);
  } catch (error) {
    Log.saveError(error, {
      message: `Error en sendClosedToPlatformsAfterRejectClosed  para branch: ${branchId}`,
      branchId: branchId
    });
  }
}

async function closeBranchPeya(branch, platform) {
  try {
    const branchName = platform.branchName;
    const branchNames = Array.isArray(branchName) ? branchName : [branchName];
    
    const headersConfig = {
      headers: {
        'Authorization': `Bearer ${tokenPeya}`,
        'Content-Type': 'application/json'
      }
    };
    
    for (const remoteId of branchNames) {
      const url = `${peyaBaseUrl}/v2/chains/${settings.chainCode}/remoteVendors/${remoteId}/availability`;
      const statusResponse = await axios.get(url, headersConfig);
      
      const body = {
        availabilityState: "CLOSED",
        closedReason: "OTHER",
        platformKey: statusResponse.data[0].platformKey,
        platformRestaurantId: statusResponse.data[0].platformRestaurantId
      };
      try {
        await axios.put(url, body, headersConfig);
      } catch (error) {
        Log.saveError(error, { 
          message: `Branch OpenClose Error: PedidosYa sendClosedToPlatformsAfterRejectClosed CLOSE ${branch.branchId}`, 
          action: 'sendClosedToPlatformsAfterRejectClosed',
          platformId: 1, // peyaId
          operation: 'CLOSE',
          branch: {
              branchReferenceId: remoteId,
              country: branch.address?.country,
              branchId: branch.branchId
          },
          request: {
              url: url,
              method: 'PUT',
              body: body,
              header: headersConfig.headers
          },
          response: {
              status: error?.response?.status,
              data: error?.response?.data
          }
        });
      }

      console.log(`Cerrado en PedidosYa: branch ${branch.branchId}, remoteId ${remoteId}`);
    }
  } catch (error) {
    throw error;
  }
}

async function closeBranchRappi(branch, platform) {
  try {
    const branchReference = platform.branchReference;
    const branchReferences = Array.isArray(branchReference) ? branchReference : [branchReference];
    const country = branch.address?.country;
    
    if (!tokenRappi[country]) {
      throw new Error(`No hay token de Rappi para ${country}`);
    }

    const url = baseUrlRappi[country] + '/api/v2/restaurants-integrations-public-api/availability/stores/enable';
    const options = {
      headers: {
        'Content-Type': 'application/json',
        'x-authorization': 'bearer ' + tokenRappi[country]
      }
    };

    for (const rappiNumber of branchReferences) {
      try {
        await axios.put(url, { stores: [{ store_id: rappiNumber, is_enabled: false }] }, options);
      } catch (error) {
        Log.saveError(error, { 
          message: `Branch OpenClose Error: Rappi sendClosedToPlatformsAfterRejectClosed CLOSE ${branch.branchId}`, 
          action: 'sendClosedToPlatformsAfterRejectClosed',
          platformId: 2, // rappiId
          operation: 'CLOSE',
          branch: {
              branchReferenceId: rappiNumber,
              country: branch.address?.country,
              branchId: branch.branchId
          },
          request: {
              url: url,
              method: 'PUT',
              body: { stores: [{ store_id: rappiNumber, is_enabled: false }] },
              header: options.headers
          },
          response: {
              status: error?.response?.status,
              data: error?.response?.data
          }
        });
      }
   
      console.log(`Cerrado en Rappi: branch ${branch.branchId}, store_id ${rappiNumber}`);
    }
  } catch (error) {
    throw error;
  }
}

async function closeBranchUber(branch, platform) {
  try {
    const branchReference = platform.branchReference;
    const branchReferences = Array.isArray(branchReference) ? branchReference : [branchReference];
    
    const headersConfig = {
      headers: {
        'Authorization': `Bearer ${tokenUber[branch.address?.country]}`,
        'Content-Type': 'application/json'
      }
    };

    const mañana = new Date();
    mañana.setDate(mañana.getDate() + 1);
    mañana.setHours(15, 0, 0, 0);

    for (const store_id of branchReferences) {
      const body = {
        "is_offline_until": mañana.toISOString(),
        "status": "OFFLINE",
        "reason": "STORE CLOSED"
      };
      const url = `${baseUrlUber}/v1/delivery/store/${store_id}/update-store-status`;
      try {
        await axios.put(url, body, headersConfig);
        console.log(`Cerrado en Uber: branch ${branch.branchId}, store_id ${store_id}`);
      } catch (error) {
        Log.saveError(error, { 
          message: `Branch OpenClose Error: Uber sendClosedToPlatformsAfterRejectClosed CLOSE ${branch.branchId}`, 
          action: 'sendClosedToPlatformsAfterRejectClosed',
          platformId: 4, // uberId
          operation: 'CLOSE',
          branch: {
              branchReferenceId: store_id,
              country: branch.address?.country,
              branchId: branch.branchId
          },
          request: {
              url: url,
              method: 'PUT',
              body: body,
              header: headersConfig.headers
          },
          response: {
              status: error?.response?.status,
              data: error?.response?.data
          }
        });
      }
    
    }
  } catch (error) {
    throw error;
  }
}

async function closeBranchMercadoPago(branch, platform) {
  try {
    const branchReference = platform.branchReference;
    const branchReferences = Array.isArray(branchReference) ? branchReference : [branchReference];
    
    const mercadoPagoPlatform = branch.platforms?.find(p => p.platform?.toString() === mercadopagoId?.toString());
    const user_id = mercadoPagoPlatform?.mercadoPagoUserId;
    const tenant = tenants.find(t => t.name === branch.chain?.trim().toLowerCase());
    
    if (!user_id || !tenant) {
      throw new Error(`No se encontró user_id o tenant para branch ${branch.branchId}`);
    }

    const tokenMercadoPagoCloud = await searchToken(user_id, tenant.tenantId, false);
    
    if (!tokenMercadoPagoCloud) {
      throw new Error(`No se pudo obtener token MercadoPago para branch ${branch.branchId}`);
    }

    const decryptedToken = await Token.decrypt(tokenMercadoPagoCloud?.token);
    const headersConfig = {
      headers: {
        'Authorization': `Bearer ${decryptedToken}`
      }
    };

    for (const store_id of branchReferences) {
      const body = { status: "paused" };

Conclusión del Archivo

El controlador de sucursales agrega un segundo camino de cierre activo: cuando orderRejClosed() detecta órdenes rechazadas por cierre, ahora también notifica a cada plataforma activa de la sucursal para que la marque como cerrada. El flujo es tolerante a fallos por plataforma (cada cierre va en un bloque independiente con log de error), y usa los tokens por país ya existentes para Rappi y UberEats. El updateMany se reordena para marcar las órdenes como procesadas antes de ejecutar el cierre, evitando reprocesos ante fallos parciales.

Conclusión General

Este release completa el ciclo de cierre de sucursales en el contexto de órdenes rechazadas por estado cerrado. Hasta ahora, orderRejClosed() procesaba las órdenes pero no notificaba a las plataformas externas. Con este cambio, tras rechazar las órdenes, el Concentrador ejecuta un cierre activo en todas las plataformas activas de la sucursal (PedidosYa, Rappi, UberEats, PediGrido y MercadoPago), usando los tokens y credenciales correctos por país. El flujo es tolerante a fallos: si una plataforma falla, el error queda registrado y el proceso continúa con las demás.
